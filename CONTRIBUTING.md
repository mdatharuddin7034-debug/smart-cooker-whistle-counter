# Contributing to Smart Cooker Whistle Counter

Thank you for your interest in contributing to Smart Cooker Whistle Counter. We welcome contributions from developers, hardware enthusiasts, students, and makers who want to improve the project.

## How You Can Contribute

You can contribute in several ways:
- Report bugs and issues
- Suggest new features or improvements
- Improve documentation
- Optimize code or embedded logic
- Enhance hardware design and reliability
- Add testing or validation for system behavior

## Getting Started

1. Fork the repository.
2. Clone the fork locally:
